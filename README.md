# Цель проекта

Создать модель, способную автоматически классифицировать отзывы клиентов на позитивные и негативные,  
чтобы сократить ручную обработку отзывов и перераспределить человеческие ресурсы.

## Целевые метрики для продакшена

| Тип метрики | Метрика | Целевое значение | Назначение |
|--------------|----------|------------------|-------------|
| Business | Сокращение времени ручной обработки отзывов | ≥ 40 % | Эффективность |
| Technical | Среднее время отклика модели | ≤ 200 мс | SLA |
| Model | Accuracy | ≥ 0.90 | Качество классификации |
| Model | F1 (по негативным отзывам) | ≥ 0.88 | Баланс precision/recall |

# Набор данных

[IMDB Reviews](https://huggingface.co/datasets/stanfordnlp/imdb)

Описание с сайта:

Dataset Summary
Large Movie Review Dataset. This is a dataset for binary sentiment classification containing substantially more data than previous benchmark datasets. We provide a set of 25,000 highly polar movie reviews for training, and 25,000 for testing. There is additional unlabeled data for use as well.

# План экспериментов
1. Загрузка и предобработка данных.  
2. Использование предобученной модели для текстовой классификации.  
3. Настройка гиперпараметров.  
4. Обучение и валидация модели.
5. Вывод метрик.  
6. Сохранение итоговой модели.  
7. Подготовка пайплайна для воспроизводимого обучения и последующего тестирования.
